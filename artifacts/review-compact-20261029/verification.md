# 复习列表精简验收

- 范围：编程英语复习页的已学词汇列表；学习规则、音频和存储格式沿用。
- 词条保留中文在前、英文、音标和就近慢速；例句按需展开，支持正常及慢速朗读。
- 每页 12 个词，上下均可翻页，支持页码直达；搜索和范围切换回到第一页。
- `npx tsc --noEmit` 通过。
- `node tools/test-review-compact-browser.mjs` 通过：分页/最后一页/搜索/筛选、展开收起、真实音频播放事件及 0.72 倍速、恢复 1 倍、收藏、学习记录保留、单词练习入口。
- 检查 1440、1024、760、390、320 五个宽度及四套配色，共 20 组，无横向溢出；已人工查看桌面、平板、手机及手机例句展开截图。
- 代表词条高度：桌面约 100px，390px 手机约 142px；长词、长释义及更窄屏幕会按内容换行。
- 标准 `npm run build` 清理原 dist/audio 时遇到 EPERM；使用 `npx vite build --emptyOutDir false` 保留原资源完成构建，再运行 `node scripts/prepare-deploy.mjs` 通过全部资源校验。
- 全程使用独立浏览器上下文及隔离测试进度。
- `tools/test-mobile-browser.mjs` 的 phone pages 场景通过，覆盖四套配色、手机页面、长词与设置；先前并行运行时一次点击超时，独立重跑通过。
