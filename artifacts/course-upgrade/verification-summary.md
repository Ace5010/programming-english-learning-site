## 已实现

| 优化 | 当前效果 |
| --- | --- |
| 一次原位纠错 | 适合的排序、局部填空、听句补词、拼写和固定短句，首次错题保留输入并标出错位、错字或缺失处；排序词块就地标黄，页面定位到纠错提示，再允许一次提交 |
| 真实记录修改结果 | 未填写、输入法组合中、未改变答案的重复检查不消耗机会；首次困难即保存，改对记辅助完成，一题只计一次最终作答，不重复扣减信心 |
| 文字／听音配对 | 两区共用；选项不重排，听音题正确配对后显示英文；每个目标分别记录，最后唯一剩余组合不算独立答对，已展示内容仍能正常／慢速点读 |
| 听句补词与排序梯度 | 复用已教原句和录音；编程填空必须考查其对应目标词。低信心偏向词组，之后偏向单词及一个已学干扰词，最多 8 个词块 |
| 日常渐进跟读 | 完整、部分遮词、隐藏文本三档，按已有表现安排；可显示文本和重录，口语自查不增加独立掌握证据 |
| 进度与声音 | 展示当前练习阶段，完成后进度到达终点，结果区分独立完成和修改正确；配对、答对、结课提示音等待朗读结束，不叠播，切题和退出取消等待 |
| 恢复与兼容 | 两区课程刷新、返回和切换风格保留草稿与纠错机会；词汇复习在同一标签页保存临时续学会话；原有存储键和词汇 ID 保留 |
