# 本地发音反馈试验（2026-09-25）

已实现 `openpronounce-feedback-v2` 并启动本机录音页 http://127.0.0.1:18765/ 。这仍是课程接入前的验证工具，未启用自动闯关判定，未修改学习记录，未提交推送。

## 改动

- 使用 OpenPronounce 的音素识别模型，另用本地 Wav2Vec2 词识别作辅助证据。去掉合成示范音相似度及文字拼写错误率评分，不需要 TTS 或联网 API。
- 用 CMU 发音词典与 eSpeak 生成合理发音变体。按音素比较辅助识别的词，因此 `GOOD BYE`/`goodbye`、`RITE`/`right` 不因拼写或分词不同扣分。
- 具体替换提示按音位给出，不使用整词错误比例掩盖单个错音。模型置信证据和辅助词识别都支持同一替换时才提示；单模型高置信也可能错，所以冲突、遗漏、额外音和弱证据保留为未确认。
- 此规则不覆盖所有英语口音；字典缺词、多义词语境、长句、连读等仍有限制。两个模型的错误可能相关，不能把“双模型支持”解释成两个人工评委或正确性保证。
- 录音页增加实时音量、录音回听、权限等待超时和请求超时；保留取消、迟到权限回调隔离、结果滚动显示。音频只在内存处理，取消或开始下一次时释放上次回听资源。

## 真实评测结果

| 数据集 | 正常样本：支持 / 误报 / 未确认 | 错误样本：误放行 / 提示练习 / 未确认 | 中位耗时 |
|---|---|---|---:|
| 原有 24 条回归 | 14 / 0 / 0 | 0 / 9 / 1 | 0.504 秒 |
| 扩展开发集 72 条 | 12 / 0 / 24 | 0 / 17 / 19 | 0.483 秒 |
| 冻结规则后的独立验证集 72 条 | 23 / 0 / 13 | 0 / 18 / 18 | 0.484 秒 |

共 168 条公开音频评测，另有静音、固定随机噪声、440 Hz 纯音 3 条控制输入，均未被支持或判为具体错音。耗时包含本地解码与两模型计算，模型已驻留；不包括用户说话时间。

旧原版 OpenPronounce 在原有 10 个错误样本中只对 1 个提示错误；v2 对 9 个给出练习提示，另 1 个 Guy bed→bad 因词识别成 BEAD，与音素证据冲突而未确认。正常 Goodbye 两套音频均获支持。

开发过程保留失败证据：v1 在首批 72 条新样本中曾误报 3 条正常 Piper 发音（chip、leave、live）。因此改为跨模型同音位核对，没有通过降低门槛强行使正常样本通过。该批样本随后归入开发集，不能继续称为未见验证集。v2 冻结后，再用新词、新音位组合的另一批 72 条验证，规则没有针对它继续调参。

独立验证集包括 seat/sit、heat/hit、safe/save、pool/pull、lock/rock、mouth/mouse；Aria、Guy、Piper 三种合成声线，各词正向和对照评测。它只支持“未见词及额外合成声线”的验证，**不能代替真人多口音验收**。31/72 条仍未确认，覆盖率不足，不能宣称已满足正式课程准确性要求。

## 真人试读未通过（2026-09-25）

用户实际试读后反馈识别准确性很差、没有获得正确识别，并确认回听声音清楚完整。现场观察到 Goodbye 的辅助词识别明显偏离目标，页面返回 uncertain，服务耗时约 0.7 秒。该结果说明当前版本未满足真人使用要求；不能把模型无法确认解释为用户读错，也不能用合成样本的低误报率替代真人可用性。用户试读的总次数与人工音素标注未取得，不能据此编造精确的真人准确率。

代码检查确认 FFmpeg 输出与两个识别模型均使用 16 kHz 单声道。另对同一公开 Goodbye 音频检查原始输入、降低 12 dB、增益 6 dB、首尾各加 2 秒静音、各加 6 秒静音及增加固定随机噪声，共 6 个本机请求，均返回 supported，耗时 532—3088 ms，见 `input-pipeline-diagnostic.json`。长静音已改变部分模型输出，尽管最终获得支持。这些检查未复现用户失败，不证明真人录音链路完全无问题，也没有查明具体失败原因。

当前暂停课程接入，提交推送继续暂缓。原页面承诺不保存，随后另行获得用户明确许可，仅在本机临时保存一段录音作诊断；未静默开启持续录音留存。

### 经授权的固定真人录音诊断

使用用户当前页面保留的一段 Goodbye 录音（晚于前述现场观察），通过回听控件下载并移动到已排除 Git 的 `.runtime/pronunciation/private-diagnostic/`。录音为单声道 Opus、48 kHz，解码后约 2.16 秒，无检测到的削波；整体 RMS 约 0.00358，峰值约 0.0343，音量偏低，但这不等于听不清或发音有错。原始录音与详细模型结果仅保留在该临时目录，不写入仓库产物。

- 当前 v2 对原始录音、PCM 往返、增加 18 dB、裁去首尾低能量区、裁剪后增加 18 dB，五种输入全部未确认，辅助词识别仍偏离目标。音素模型也没有恢复出稳定的目标序列。因此没有证据支持通过简单增益、裁剪或修改判定阈值解决本次失败。
- 已缓存的 Whisper small 未提供目标文本提示，对原始录音转写为 Goodbye，单次约 1.314 秒；公开 Goodbye 与 sheep 对照分别转写正确，静音输出为空。它是词句识别候选，不是音素发音评测通过证据，也没有证明多词、多口音准确率。
- 已缓存的 Whisper large-v3 同段转写为 Goodbye，约 6.826 秒；静音还出现了无关文字输出，伴随较高的 no-speech 概率，说明不能忽略语音检测证据。
- 已有 TIMIT 量化音素模型对同段也没有得到与目标一致的序列。这是模型输出，未经人工音素标注，不能据此认定具体哪个音读错。

结论：本次复现将问题缩小到当前识别与判定链路对真人输入的适用性，尚未建立可用的逐音正确性判断。撤回将当前 OpenPronounce 组合用于正式自动评测的推荐；Whisper small 只保留为进一步验证的转写候选。没有新增云端请求或费用，没有通过放松门槛或强制目标文本来放行，没有修改正式课程。
