# 编程课程留白与居中调整验收

2026-10-04，当前工作区 `D:\vibe项目\Interactive learning`，沿用 `main`。本轮仅调整编程课程首页版式、对应浏览器布局断言和说明文档。

用户先要求减少学习区占满页面的厚重感、恢复右侧留白；查看初版后补充“太靠左了，就中间一点”。最终版将学习区和右侧进度作为一个整体居中，没有重新扩大内容宽度。

## 最终版式

- 宽屏学习区最大 900px，右侧进度 240px，两者之间 40px；内容组在页面内居中。1440px 视口实测内容组左右外边距均为 130px，学习区从最初的 x=56 移至 x=130。
- 移除贯穿六张词卡的大渐变外框，将浅色渐变和重点色集中到标题区；词卡之间显示白色页面背景，卡片边框减轻。
- 保留中文释义的视觉优先级、展开的用法和例句、逐条正常与慢速点读，以及下方的开始／继续测试入口。
- 窄屏内容组限制宽度并居中；手机仍为一列，课程进度放到下方。

## 实际检查

- `node tools/test-programming-word-check-browser.mjs`：19 个场景通过。包含四套配色的 1440／390／320px 布局、正常／慢速真实播放事件、六词与十题流程、保存恢复、跳过恢复及复习切换。
- `node tools/test-course-home-browser.mjs`：12 个场景通过。包含两区首页、新旧会话、配色及 768／390／320px 布局；编程课程额外验证宽屏内容组居中，主题切换和刷新不改学习记录。
- `node tools/test-mobile-browser.mjs`：13 个场景通过，覆盖四套配色、手机页面及键盘高度下的题目可达性。

上述 44 个浏览器场景使用隔离的本机 Chrome 无头浏览器与当前开发服务；不作为 Android 真机或线上部署证据。本轮没有修改 React／TypeScript 运行逻辑、课程编排或存储，也未提交、推送或发布。
