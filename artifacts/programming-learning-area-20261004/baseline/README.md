# 英语学习网站

这是一个面向零基础学习者的中英双语英语学习网站。编程英语帮助阅读 GitHub、代码和技术文档；日常英语提供独立的生活交流课程；英语基础提供独立的语法与发音教程；前两个分区保留学习记录，基础教程不新增学习记录。

## 课程、复习与查询

编程和日常分区各有“课程、复习、词汇库、收藏”入口，英语基础提供独立教程。编程每节约 6 个全新词：先自行点读、跟读和理解，再主动开始 10 题检验；答错不加题，旧词不回流新课。最后不足 6 个词时缩短题量。日常继续按实际表现动态补弱和安排新内容。完整说明见 [课程系统](docs/COURSE_SYSTEM.md)。

编程课程首页的“本节课会学到的词语”是主要学习区：大词卡以中文释义为先，直接展示英文、已有音标、中文用法和双语例句，容易混淆的词附简短对比。点击中文、英文或词卡空白处朗读单词；点击例句朗读整句，每条内容都有就近的慢速按钮。学好后从词卡下方直接“开始测试”，无需再进入重复的学习页。

- **编程英语**：原有 4 单元、24 个教学材料范围覆盖 63 个核心词，附有作者题目与扩充候选题库。它们是编排素材，不是固定的 24 节课程。围绕 GitHub、代码说明、终端文件工具、错误测试调试，以词义和简单语境识别为主，拼写最多一道，普通新课不安排口语识别或听写。详见 [编程课程](docs/PROGRAMMING_ENGLISH.md)。
- **日常英语**：保留 A1 前四单元的 24 个材料范围、83 条双语点读材料及原有口语、键盘和判题方式，组合成动态课程。后续 A1 与 A2/B1/B2 尚未制作，不显示空入口。
- **英语基础**：语法采用自由阅读目录；发音首页为完整的英式 44 音表，单音、例词、慢速、中文发音说明及易混音对比直接可用。表内来自 Cambridge 的 88 段录音已本地保存，点读不访问外网；原有 56 个主题与两篇样章保留为补充讲解。不提供复习、收藏或学习统计，可从原课程打开讲解并返回。原双声线 596 个本地录音保留；样章中的 BBC 外部视频仍需联网，未取得播放验证。详见 [英语基础教程](docs/FOUNDATION_ENGLISH.md)。
- **学习与复习**：编程学过的词继续进入原复习列表，方便重新点读与主动练习；可复习不等于已经掌握，实际测试成绩单独记录。日常继续按信心和间隔迁移条件准入，薄弱内容可回流后续课程。
- **真实能力**：编程词汇分别记录词义、语境、拼写与听力；只更新实际考查方向。同日纠正、提示后完成和口语自查不会冒充长期记忆或自动评定的能力。
- **旧学习记录**：原来手动标记掌握的词继续进入复习并跳过全新教学；历史标记和实际答题证据保留。编程复习困难继续留在复习，不回流新课。不再提供手动掌握按钮或已掌握分区。
- **查询与收藏**：编程词库共 3,620 个词；日常表达库支持搜索、收藏及学习状态。点亮星标后，可从顶部“收藏”直接查看本分区的收藏，支持搜索、正常／慢速点读和取消收藏；以前的收藏沿用原记录。收藏页搜索与词汇库／表达库筛选独立。单纯浏览、点读、收藏不会计为课程学习或答对。
- 统一白底布局，提供蓝绿、黑白、冰蓝、薄荷绿四套配色；保留 Aria/Guy 双声线、正常/慢速和真实播放反馈。配色切换不会重置练习。学习记录优先保存在本机，可通过私人同步码连接自己的手机和网页。无需注册账号；未开启同步的设备仍独立使用。课程算法不调用 AI 服务。界面验收见 [配色与动效改版](docs/PALETTE_ROLLOUT.md)。

## 安卓测试版

提供内置完整词库、课程及两套录音的离线 APK，复用网页版学习逻辑。手机布局增大逐条慢速等控件的触控区域，适配安全区域，并使答题输入框避让键盘和底部按钮。1.1.2 在安卓上由系统播放器直接读取包内录音，支持逐条正常／慢速；加载中连点不会取消读音，卡住时可恢复并重新点读原词。安卓壳接入系统语音识别和文件导出，不新增存储权限。在已有进度的网页点击顶部“同步”→“开启同步”，再在安卓应用输入同一同步码，即可自动同步课程、复习、已掌握词和收藏；断网后本机继续保存，联网后补传。

构建方法、实际检查和仍待真机验证的项目见 [安卓测试说明](docs/ANDROID_TESTING.md)。安装包是本地生成文件，不提交到 Git；后续更新须使用原包名和原签名，并增加版本号。

## 词汇与录音

原有 3,560 个词及 ID 全部保留，追加 60 个常用词，并补充部分旧词的技术释义。Aria/Guy 各 7,241 个 MP3：3,620 单词、3,620 例句、1 个试听。日常音频仍为每声线 83 个；旧 Piper 的 7,122 个 MP3 冻结保留供回溯。补充清单及验证见 [常用词补充](docs/VOCABULARY_EXPANSION.md)。

## 主要实现

- `src/App.tsx`：三个分区、四类入口、共享语音与编程词库。
- `src/DailyEnglish.tsx`：三区复用的教学、练习、续学、解锁与场景复习界面。
- `src/FoundationEnglish.tsx` / `src/foundationCourse.ts`：独立教程、两篇样章、主题目录与历史课程兼容内容。
- `src/PhonemicChart.tsx` / `src/phonemeInventory.ts`：英式 44 音交互表、中文动作提示和 Cambridge 原站单音／例词映射。
- `src/dailyCourse.ts` / `src/programmingCourse.ts`：两区独立课程内容。
- `src/dailyPractice.ts` / `src/programmingPractice.ts`：带知识目标、难度及题面签名的候选题库。
- `src/adaptiveLearning.ts` / `src/learningTypes.ts`：本地动态课程编排、逐题选择、学习证据与长期复习准入；不调用新的 AI 或后台服务。
- `src/dailyProgress.ts`：兼容旧记录的课程与知识级表现；分别写入 `codewords-daily-v1`、`codewords-programming-course-v1`。
- `src/programmingProgress.ts`：旧词复习准入、编程课程到词级复习的幂等衔接。
- `src/review.ts` / `src/lesson.ts`：四能力记录、动态题型与间隔；沿用 `codewords-review-v1`，兼容旧两能力记录。
- `src/vocabulary.ts`：完整查询词库；生成器锁定原 ID 后追加，不重排旧词。

学习状态通过原格式的可选字段扩展，不重置旧记录。当前计划、随机状态、已选题目、输入、提示和反馈都会保存，刷新后继续原题，不重新抽题。损坏或未知版本记录保持原文并停止写入；跨标签页冲突时停止旧页保存。导出记录保留原始文本。跨设备同步使用原始记录快照及版本比较；收藏合并，课程／复习冲突先保留两份，再由使用者决定继续哪份。详见 [设备同步](docs/SYNC.md)。设计、边界及分阶段验收见 [课程系统说明](docs/COURSE_SYSTEM.md)。

## 直接运行

建议使用 Node.js 24；日常课程校验读取 TypeScript 数据需要 Node.js 22.18 或更新版本。在项目目录运行：

```powershell
npm install
npm run dev
```

本地开发地址固定为 `http://localhost:5186/`，端口被占用时会报错，不会自动换地址。
日常使用可双击桌面的 **英语学习（本地）** 快捷方式，或项目根目录的 **启动英语学习.cmd**；无需手动打开终端。入口会在后台启动本项目、核对页面及进程身份、等待就绪后打开 Chrome。重复启动会复用现有服务；缺依赖或端口被其他程序占用时显示中文提示并保留诊断日志，不停止其他程序。
也可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Open-LocalSite.ps1`；加 `-CheckOnly` 会启动并检查服务，但不打开浏览器。默认使用原端口；`-Port` 仅用于隔离启动测试，`-SkipSpeech` 可跳过可选的本机识别服务检查。识别服务检查安排在打开页面之后。
本机已有模型环境时，启动器默认启动 Qwen3-ASR-1.7B，日常跟读等原识别页面的录音仅在这台电脑处理且不保存，无需 API Key；编程新词学习与检验无需识别服务。模型稍后就绪时原跟读页面会自动接入，界面显示实际识别来源；其他设备保留原设备／浏览器语音识别。筛选与正式接入验证见 [跟读模型替换](docs/ASR_REPLACEMENT.md)。
本地学习记录属于浏览器和地址，换端口前需要备份并迁移；线上 Pages 的记录与本地独立。

构建静态网页：

```powershell
npm run build
```

检查词汇、语音和关键项目文件是否完整：

```powershell
npm run verify
```

## 重新生成词汇

```powershell
npm run generate:vocabulary
```

生成器使用本项目 `sources`、固定身份清单 `scripts/vocabulary-baseline.json` 与补充清单 `scripts/vocabulary-expansion.json`，不依赖原工作目录。不要通过重排来源重新编号已有词。

## 重新生成固定语音

当前 Aria / Guy 双声线的再生成方法见 [双声线说明](docs/NEURAL_AUDIO.md)。以下保留旧 Piper 音频的再生成方法，仅用于回溯。

先创建 Python 环境并安装 Piper：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r tools\requirements.txt
```

生成缺失语音（已有文件会自动跳过）：

```powershell
.\.venv\Scripts\python.exe tools\generate_piper_audio.py --site . --model tools\models\en_US-lessac-medium.onnx
```

工具还支持 `--start`、`--limit` 和 `--force`，可分批生成或强制重建。

## 说明

- `node_modules` 已保留在本地整合目录中，方便直接运行；它属于可重新安装的依赖缓存，不计入固定资产校验清单。
- Python `.venv` 属于机器环境，未固定打包；可用 `tools/requirements.txt` 在项目内随时重建。
- Piper 模型文件已经收进项目，重新生成语音时无需再单独下载模型。
- `dist` 是本地构建产物；GitHub Actions 会在每次推送到 `main` 后重新构建并部署到 GitHub Pages。
