# 编程英语主要学习区验收

日期：2026-10-04。当前工作区：`D:\vibe项目\Interactive learning`，沿用 `main`。

按用户本轮确认，将“本节新词”改为“本节课会学到的词语”，作为课程首页的主要学习区。学习区占满内容宽度，重点色边框与浅色渐变突出；桌面两列词卡，手机一列。课程进度移至下方。每张词卡中文释义在前，直接展示英文、已有音标、中文用法、双语例句和必要的易混对比，不再折叠主要学习内容。

点击词卡的中文、英文和空白处，正常朗读单词；点击例句或例句背景，正常朗读整句。每条内容就近提供独立慢速按钮，慢速为 0.72 倍并保留音高，之后正常点读仍为 1 倍。重复点击重新播放；慢速与例句点击不冒泡触发单词录音，播放状态跟随真实音频事件。

用户在首页自行学习后，从词卡下方“开始测试”直接进入第一题。已保存的教学会话沿用规范后的范围、队列和会话 ID；已开始的测试显示“继续测试”，保留题目、答案和草稿。尚未答题的自适应之前的旧教学页也迁移为六个新词，原题及草稿留在 `replaced`。尚未结束的复习须由界面中的切换操作明确确认，提示自动回到可见位置，确认前不覆盖原复习。

本轮保留已确认的六个全新词、通常十题、最多一道词级拼写、无强制语音识别、错误不加题、旧词不自动回流及原复习词表。日常英语的教学与判题规则继续使用原逻辑。`src/programmingStudy.ts` 为原 63 个课程目标补齐中文阅读说明；原英文例句、词汇 ID、音频、存储键与版本不变。

## 回归中发现的问题

初测的两个失败来自测试夹具：撤销跳过正确恢复“尚无 learning”的状态，断言却假定字段已存在；另一处错误使用日常准入生成编程复习，导致夹具无有效队列。校正为可选字段检查及真实编程学习证据生成的复习后通过，原初测报告保留在 `browser-initial-report.json`。

历史首页测试另发现自适应之前的旧教学页没有进入直接检验路径。已增加只针对未答题旧编程教学页的迁移，保留原会话 ID 和草稿，并增加规则回归；两区 12 个首页场景全部通过。

切换提示在未完成复习时曾处于视口上方，复现位置为 `y = -1101.21875`，证据在 `notice-before-fix/report.json`。增加定位后，最终开发／生产专项都确认提示处于视口内，确认前原复习记录不变。
