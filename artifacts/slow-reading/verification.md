# 逐词慢读验收记录

2026-09-28。本地实现与自动化验收完成；主观听感及实体手机扬声器尚未验收。没有提交、推送或发布。

## 已实现

- 原有正常朗读继续播放完整录音，单词慢速保持 0.72 倍；句子和多词短语由同一播放器完成逐词慢读。
- 网页复用一次点击启动的媒体元素；安卓一次接收整个包内片段队列。停顿期间保持忙碌状态、同步保护和提示音等待；取消后不续播。
- 缩写、复数、大小写、金额、数字及技术写法进入完整清单；read/live/use/record/close/used 按现有语料语境选择读法。
- 原音频只读复用；缺口离线补录并按声线打包。文件与片段均校验，资源版本进入 URL，避免缓存错配。
- 学习存储键、记录结构、课程算法、判题和提示证据逻辑未改。

旧局部播放测试仍使用已移除的课程列表与“界面风格”定位器，本轮更新为当前课程首页、日常复习页和“界面配色”。基础测试的播放探针改为每个媒体元素只注册一次，避免队列复用媒体元素时重复计数。最终各测试结果均通过。

## 安卓

Release、Debug、Android Lint 通过。正式候选包 [codewords-slow-reading-release.apk](../android/codewords-slow-reading-release.apk) 保持原包名和签名，版本号仍为 1.1.3，未发布。

- APK 大小 262,642,734 字节；SHA-256 `5a152c5570675cff4b60af905e402c77d86fa1e9ea7ff84c24a18e0ea9ca9227`。
- [APK 内容核对](apk-validation.json)：15,994 个内嵌网页文件与当前 dist 逐字节相同，含 15,971 个 MP3；没有打包签名配置或私钥。
- [签名](apk-signature.txt)：v2 验证通过，沿用本机 CodeWords 签名。
- [真实原生测试](android-results.json)：MuMu Android 12 / WebView 110，独立 `com.codewords.english.slowqa` 调试包。使用同一网页和 Java 源码，测试包明确移除 INTERNET 权限；未切断模拟器全局网络。
- 14 场景通过：两声线各 6 个正常/慢速/缩写/复数/11 词长句场景，加连点切分区、后台取消。断网能力由无联网权限的包验证；日志与网页探针确认发声走原生桥，未走 HTML 回退。
- 实测发现原 MainActivity 的 512 字符音频消息上限会丢弃长句，已改为队列最高 65,536 字符，同时保留 256 片段上限、同声线、时间范围和受限包内路径校验。修复后重新构建与重跑。
- 日志环形缓冲区会淘汰旧行，测试因此按最新请求取证，避免把旧行被移出缓冲区误判为取消失败。

## 样音及未确认事项

[Aria 实际浏览器录音](aria-actual-browser.mp3)、[Guy 实际浏览器录音](guy-actual-browser.mp3) 均来自一次点击播放 `I am a student.` 时的真实媒体输出。MP3 由同目录 WebM 录音转码。

约 -48 dB 静音检测测得 Aria 的三处词间空白为 273 / 274 / 293 毫秒，Guy 为 288 / 343 / 305 毫秒。它们支持“约 300 毫秒”的目标，不等于主观听感确认，也不代表全部语料逐段人工审听。浏览器/设备寻址及计时会影响实际间隔。

已提供样音询问用户；截至本记录尚未收到听感反馈。实体手机安装、扬声器输出与用户对停顿/语速的确认仍待验收，不能以浏览器或模拟器事件替代。
