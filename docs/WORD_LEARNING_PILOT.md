# 重点词学习试行

按 2026-09-28 确认的方案，在保留原有两区课程、分区隔离和动态题池的基础上补充词级证据。

日常英语先试行 from、student、teacher。课程材料中的同一重点词共用 `daily-word-*` 记录；原整句记录保留。只为人工指定的来源、身份表达增加重点词，不自动把整句拆成背词任务。教学页保留完整表达和 a student / a teacher 搭配。新增 3 个单词的两套录音放在原日常音频目录，原音频 ID 不变。

词义辨认之后可出现局部补全、中文提示写词、无选项补词、听句补词。听句题明确挖目标词，另以已介绍的整句为前置条件。冠词困难可进入搭配填空，不能凭该题给单词新增换句迁移证据。没有固定每词次数；试行的 4:6 只影响选题权重，薄弱程度、间隔和可用题目仍会改变实际比例。

整句书写只在其他词一致且有一个近似拼写错误时归到对应重点词拼写；漏掉单数身份前的 a 则归为搭配困难。无法可靠定位的变化仍留在表达层，不归罪于其他单词。纠错后的再次提交记为帮助后完成，不重复扣减同一个词。

`learningContext` 表示实际句子或代码上下文，`learningSignature` 表示具体题目。相同句子换题型不会产生换语境迁移。日常完整表达的间隔独立回忆单独记录，可以达到表达自身的复习准入；重点词仍要求不同已学句子的证据。编程英语保留阅读重心，新增无首字母填词并复用已有代码与说明语境，不要求每个长词无提示默写。

课末“巩固本课重点词”以及日常词汇库里的“练习这个词”共用课程目标记录。专项补练是有界的动态课程轮次，不绕过长期复习准入，也不打断未结束的课程。已准入目标继续沿用原复习流程；旧记录不重置，历史完成课不会自动给新增词创造学习证据。

## 效果检查

新增可选 `learning.targets[id].evidence`，分别累计选择辨认、无内置提示的回忆、换句、下一会话首次回忆的尝试数与独立／提示／展示答案次数。维度可以重叠；前一次已在本会话看到同词的题目，不作为下一会话首次回忆。时间是作答间隔，包含暂停，不能称为净学习耗时。旧记录没有这些字段表示未测量。

导出对应分区的学习记录后，本地运行：

```powershell
node tools/summarize-word-learning.mjs <课程导出文件.json>
```

回归与浏览器测试使用隔离的合成学习数据。它们验证机制和保存链路，不能证明真实学习效果；撤去选项后的正确率、下一次学习及换句表现，需要用户实际使用后再比较。同步回归使用本地模拟服务，未调用用户的线上同步数据。

## 验证入口

- `node --test tools/test-word-learning.mjs`：归因、换句判据、补练范围、旧数据、两端同步、统计校验。
- `node tools/test-word-learning-browser.mjs`：四套配色、真实本地音频播放、纠错刷新、课末补练；证据在 `artifacts/word-learning/`。
- `node tools/test-mobile-browser.mjs`：原两区手机与键盘布局回归。
- 课程原有测试、完整准入测试、类型检查、生产构建、项目完整性，以及日常和补充录音完整解码仍需运行。

2026-09-28 本轮结果：相关批次 116 项通过（包含编程完整课程准入），最后补充的独立词纠错去重回归连同词级套件 9 项通过；浏览器 8 场景、原手机 13 场景通过。类型检查、生产构建与项目完整性通过；172 段日常音频、582 段补充音频及 3 段反馈音效完整解码通过。浏览器实际验证了新增 student 正常／慢速播放；全部新增录音的浏览器逐条播放和 Android 真机未做，本轮没有线上发布。
