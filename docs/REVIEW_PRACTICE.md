# 复习练习维护说明

## 2026-09-22 当前规则

编程新内容先在课程中学习，达到信心与间隔迁移条件后才进入长期复习池；首次教学只标记正在学习，不能因一次答对准入。原有手动确认过的词与历史合法复习记录继续兼容，保留旧 `codewords-mastered` 原文，跳过作为新词的教学；前端移除手动掌握机制。到期复习只取到期词，主动提前练习也只针对已准入内容。

编程复习首页直接展示已准入词汇，包括历史手动确认掌握的词。列表复用词汇库的释义、例句、点读和收藏，支持中英文搜索，以及全部已学、待复习、需要巩固、未到期筛选；每词显示到期状态和实际薄弱能力。可以练习单词、当前筛选结果或全部到期词，启动时重新读取记录检查准入，学习中的词不会混入。场景复习放在同页的折叠区，进入场景题目后隐藏列表，返回时仍使用原来的课程会话与保存逻辑。日常英语复习规则未改变。

页面实现为 `src/ReviewVocabulary.tsx` 与共享词条 `src/VocabularyRow.tsx`；`DailyEnglish` 的复习插槽仅负责组合页面，不改变题目和进度算法。页面回归脚本为 `tools/test-review-page-browser.mjs`，使用隔离浏览器与真实课程答题所得的测试记录。

每词分别记录 meaning（词义）、context（语境）、spelling（拼写）、listening（听力）。旧词义/拼写证据不改写为听力或语境证据；新增能力从未测开始。选择下一能力优先真实薄弱到期项，再看其他到期能力，同等条件偏向阅读。听辨不算拼写正确，句子理解不算词义正确。每轮至多五词，两次间隔出现，必要时安全配对；有限追加变式，不再固定旧十题模板或听写比例。

学习期由 `src/adaptiveLearning.ts` 逐题加权选择候选材料，按目标和实际能力积累信心；识别题增益较低，间隔后换题独立完成才形成迁移证据。达到条件后保存 `readyAt`，编程桥接对应的 `reviewReadyAt`。实际课程节数与每词考查次数不固定，原 24 个范围仅提供教学素材；薄弱目标继续在后续动态节中补学。

分题型保存完成次数、正确、提示和错误。提示即时保留困难，但不重复计作一道已答题。课程进度先保存，再通过持久化回执幂等同步词级证据；刷新不重复统计，衔接失败停止课程写入并保留会话以便重试。长期复习发现新的困难时降低对应学习目标信心，使其回到下一节补学选择，同时保留既有准入时间与复习资格。

`codewords-review-v1` 保持版本 1，词记录兼容增加可选 listening/context、学习来源、首次学习与准入时间、课程回执；能力记录兼容增加答题计数、formats 与来源。课程键通过可选 `learning` 和会话 `adaptive` 扩展，保留原完成及能力记录。动态课程的随机状态、题目、草稿与反馈可以刷新续接，不重新抽当前题。独立词汇复习页面仍逐次保存已答表现，未完成的模态题目队列不承诺刷新恢复。

长期复习保持原有隔日有效回忆与 1/3/7/14/30 天间隔，不把同日刷题或帮助后的正确当作长期记忆。日常复习按表达目标做相同准入检查，仍区分理解、听力、书写和口语；口语自查不能自动证明掌握。两区课程与练习册合并，首次学习和未稳定内容留在课程，准入后的到期与提前巩固放在复习。

当前实现是一套可本地检查的规则，没有新增 AI、后台或私有模型。动态验收见 [课程系统说明](COURSE_SYSTEM.md) 与 `artifacts/adaptive-course/`；旧固定课程的 48 课、240 道 UI 记录不代表这一版动态编排已经验收。

以下为旧版复习引擎的详细背景；“已掌握准入”“仅两能力”“固定10题”由以上规则替代。键盘、纠错、数据保护等未冲突部分继续适用。旧测试脚本需按其对应版本与实际结果解读，不把存在脚本当作当前验收通过。

## 历史实现背景

从已掌握词汇中安排一轮混合练习。采用全屏单任务、固定底部“检查 / 继续”、即时纠错和后续变式复查，不包含闯关、分数奖励或排行榜。

## 历史：题型和一轮流程

每轮最多选 5 个词、10 项基础任务，另加最多 5 项纠错复查。词汇不足时缩短；一项配对任务可以包含 2–3 个词，每个词单独记录结果。

- 词义选择：看到英文，选择中文含义。
- 单词配对：先选英文，再选中文；配对完成后进入反馈。第一次配错显示对应关系并允许重选，第二次配错代为完成该词，不影响其他正确配对的词。
- 听音选词：正常或慢速播放，选择听到的英文。
- 渐进听写：补少量字母 → 补约一半字母 → 只保留首字母 → 完整输入。数字和符号保留为题面线索。
- 句子选词填空：显示带空缺的英文例句和中文句意，再选择英文。中文是题型自带线索，避免多个选项都能组成合理英文句子，不计为额外帮助。

典型流程先练两个词，再配对其他词，随后穿插听音选择、句子填空和听写，同词多次出现时尽量隔开。配对会避开含义重叠的组合；不能安全配对的词拆成单题。例句没有精确目标词或明确括号缩写时，不强行生成填空。

选择题只选择、不立即提交；点击“检查”后显示答案，再点击“继续”。配对逐项即时检查，全部配完进入“继续”。听写出错显示简短的字母纠错和正确拼写；“提示”提供字母或排除选项，“暂时不会”显示答案。

听写题进入时自动聚焦输入框。补字母可连续输入，输入法确认后也会跳到下一空；左右方向键在可填写的格子间移动，输入字母直接替换当前格。Backspace 删除当前字母，空格上按 Backspace 则退回删除上一格；Delete 只清除当前格。Tab / Shift+Tab 保留正常焦点切换。填完按 Enter 检查，再按 Enter 继续；尚未填完时 Enter 定位到第一个未填空格，输入法选字期间不会提交。

每个困难词最多追加一次变式复查，总任务数不超过 15；无法穿插其他词时留到下轮，不强行立即重复。听写困难会降低尚未作答的同词听写难度。词义错误不降低拼写难度。

## 历史：调度与长期证据

- `src/lesson.ts`：混合任务规划、变式复查和结果摘要。
- `src/ReviewLesson.tsx`：全屏页面、流程、焦点和持久化。
- `src/LessonExercise.tsx`：五种练习交互。
- `src/review.ts`：词义与拼写的长期记录、选词和间隔调度。
- `src/ReviewSpelling.tsx`：沿用的拼写规范化与局部纠错工具。

选词优先照顾薄弱到期词，并在存在未测词时保留至少一个未测名额。没有足够到期词时允许提前巩固。

每词分别保存 `meaning` 和 `spelling`。`independent` 表示没有额外帮助或错误，可能仍包含题型自带字母线索；`assisted` 为借助提示或纠错完成，`revealed` 为显示完整答案或答错后纠正。

`ReviewQuestion.exposed` 标记本轮已见过该词的练习；听音选择也标记为暴露，只能证明辨认，不能冒充完整听写。后续练习可以减少字母提示，但不据此直接提高长期等级。高于已确认等级的挑战失败可记为困难，但不再额外降低已确认等级。

长期进阶要求该能力已到期、在本地日期内首次练习、当日没有困难、没有额外帮助、非暴露且非复查；听写难度还必须与已确认等级一致。拼写每档需两个不同到期日的有效独立完成，升档后计数归零，次日练新难度。最高档稳定后间隔按 1、3、7、14、30 天延长；词义单独维护相同间隔序列。

困难会重置成功计数、安排次日复习；同日重复困难不会反复降级。反复刷题和同轮纠正不算隔日回忆，也不清除原有薄弱状态。结果按词说明词义与拼写的实际表现。

## 历史：本地记录与兼容

既有掌握、收藏、语音、测验次数和旧成绩键不删除、不迁移。`codewords-quiz-last-tested` 继续保存最近完成时间，旧时间戳不推断能力等级。

新增 `codewords-review-v1`，格式为 `{"version":1,"words":{}}`。`words` 按词汇 ID 索引，包含 `meaning`、`spelling`，各有 `level`、`streak`、`intervalDays`、`dueAt`、`lastPracticedAt`、`lastSuccessDay`、`lastFailureDay`、`needsPractice`。时间戳是毫秒，日期为本地 `YYYY-MM-DD`。

格式损坏、版本不支持或读写失败时，保留原数据并显示保存提示，允许在内存中继续练习，禁止用空记录覆盖。每次保存前重新读取并合并，保留其他标签页对无关词的更新。

错误或主动提示立即保存困难记录，提前退出也保留；完成题目后更新旧时间。完成最后一项并点击“完成复习”才累计完整轮次。刷新不恢复尚未完成的题目队列。

```powershell
$env:CODEWORDS_TEST_URL = 'http://localhost:实际端口'
# 无法直接解析已有 playwright 时才设置此路径。
```
