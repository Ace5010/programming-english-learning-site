# 编程英语正式课程

编程英语复用日常英语的教学卡、答题交互和课程进度实现。原材料在 `src/programmingCourse.ts`，扩充候选题在 `src/programmingPractice.ts`，编排在 `src/adaptiveLearning.ts`。按用户 2026-10-04 的决定，课程分为自主点读学习和新词检验，只展示当前一节；每节约 6 个全部未学的新词、10 道检验题，不再混入旧薄弱词或根据错误追加题目。日常英语原自适应规则独立保留。

第一阶段素材保留 4 个单元、24 个教学范围、63 个核心词。原作者材料每范围有 5 道主练与 2 道变式，每单元末范围负责综合；这些都是候选素材。新课按材料顺序取未学、未跳过的 6 个词，允许跨范围组合，不把 24 个范围固定为 24 节。最后不足 6 词时按剩余词数缩短检验，全部学过后不再重复推送新课。整个 3,620 词词库仍独立作为查询和收藏资源。

| 材料单元 | 六个教学范围（非固定实际课次） |
| --- | --- |
| 看懂 GitHub 项目 | 仓库里有什么；复制到哪里；在分支中工作；保存一次修改；同步修改的方向；读一段协作说明 |
| 看懂代码里的基础英语 | 函数和存放数据的名字；传进去和返回来；数据是什么类型；对象里有什么；条件、循环与方法；读懂一段代码说明 |
| 终端、文件与开发工具 | 文件放在哪里；终端中的一条命令；安装需要的软件包；构建与脚本；环境、配置与浏览器；照着 README 启动项目 |
| 错误、测试与调试 | 错误不都是一回事；测试通过了吗；读日志再定位；把问题写清楚；读懂缺失和权限提示；读一次失败报告 |

## 教学和题型

课程首页的“本节课会学到的词语”是主要学习区，桌面限制宽度并将学习区与进度组成的内容组居中，右侧放简短课程进度并保留留白。重点色和浅色渐变集中在标题区，词卡之间露出白色页面背景；桌面两列词卡，手机一列。每张卡以加大加粗的中文释义为先，紧接英文、已有音标和慢速按钮，下方只保留一组双语例句；按用户 2026-10-04 最新反馈，去掉用法说明、易混对比和重复的例句标签，收紧卡片内边距及间距。`src/CourseWordCards.tsx` 共用首页和旧学习会话的展示，`src/programmingStudy.ts` 保留音标及原中文说明数据，说明不再显示在词卡；例句与录音仍对应原词汇 ID。

点击中文、英文或词卡空白处立即正常朗读单词，点击例句或其背景朗读整句；局部慢速独立播放，事件不冒泡触发另一个录音，重复点击可重新开始。播放标记跟随真实播放事件。浏览和点读不写能力证据。用户自行点读、跟读到顺利后，从词卡下方主动点击“开始测试”直接进入第一题，不使用语音识别或发音评分作为开始条件，也不再重复展示另一页学习词表。已保存的学习会话使用原范围和队列开始；已开始的测试显示“继续测试”，保留当前题目、答案和草稿。尚未结束的复习可先保留，在确认切换后才开始新课测试。

检验以词义和简单语境选择题为主，最多一道词级拼写填空；先覆盖本节各词，再选择不同含义或语境的检查，不让同一道题换 ID 重复出现。

检验目标仅限本节新词；已学词可作为题面的已知背景。正常一节完成 10 次作答即结束，不因答错补题或强制改答，结果显示本次认得与仍不熟的词，并可回原复习词表点读。最后剩余少于 6 词时最多每词 2 道、合计不超过 10 道。后续课程继续新词，旧词不自动回流。

历史候选中的听力、排序、书写和口语题保留，用于旧记录、主动专项及原复习兼容，不进入普通新词检验。课程中的命令和路径仅是阅读材料，不会在电脑上执行。

## 词汇、声音与学习记录

课程用精确的 `word` 查找既有 `VocabularyItem.id`，缺词时直接报错，不能默默创建另一套 ID。每课 `wordIds` 列出本课教学目标；每题 `wordIds` 只列该题考查的目标，`ability` 区分 `meaning`、`listening`、`spelling`、`context`。`knowledgeIds` 使用 `word-{id}`，供共享课程进度记录定位具体知识。

教学卡的 `word-{id}` 和 `example-{id}` 使用原词库英文及相同 ID 的 Aria / Guy 音频；词义优先使用本课编程含义，例如 project 显示“项目”。本次没有改动英文文本或录音文件。阅读题只使用已有材料，不把其他录音冒充为题面短句的音频。

确认结束学习并开始测试后登记首次学习时间，学过的词通过 `src/programmingProgress.ts` 进入原复习词表，供继续点读和主动练习；默认次日安排客观复习。实际题目、提示和错误继续保存，未测试能力不增加成绩，复习可用不代表目标达到 `readyAt` 或已经掌握。课程进度与日常英语独立保存，浏览、收藏和点读不代表答对。

历史手动标记和原复习中的已学词继续复习，并跳过作为新词的教学，不伪造分能力答题证据，也不因复习失败回流新课。词汇库不再提供手动掌握开关。原存储键、版本 1、旧完成记录和真实能力证据保留；`courseMode: word-check` 为可选扩展。旧课已开始时保留教学范围及答案，替换不适用的待答题并保存原草稿；下一课使用 6 个全新词。刷新继续已保存的题目和反馈。

`src/programmingReview.ts` 让场景复习和词汇复习共用四项能力记录，原点读界面、能力筛选、到期与难点安排继续保留。复习失败只改变原复习记录，不再改变新词课程候选。共享课程内的旧课级记录保留作历史，不另作为编程词的掌握度。当前系统使用本地规则，没有新增 AI 或后台。
