# 编程英语正式课程

编程英语复用日常英语的教学卡、答题交互和课程进度实现。原材料在 `src/programmingCourse.ts`，扩充候选题在 `src/programmingPractice.ts`，动态编排在 `src/adaptiveLearning.ts`。课程与原练习册合并；只显示当前动态生成的一节，不提前列出未来课程和单元。下一节根据实际薄弱目标与学习表现编排，实际课数不固定为 24。

第一阶段素材保留 4 个单元、24 个教学范围、63 个核心词。原作者材料每范围有 5 道主练与 2 道变式，每单元末范围负责综合；这些都是候选素材，不再规定用户一节必须完成哪 5 道题。教学卡按本节重点选择词语和例句，答错较多时下一节多补旧、少加新，学习顺利时继续引入新内容。整个词库仍独立作为查询和收藏资源，不把所有词条强制变成课程。

| 材料单元 | 六个教学范围（非固定实际课次） |
| --- | --- |
| 看懂 GitHub 项目 | 仓库里有什么；复制到哪里；在分支中工作；保存一次修改；同步修改的方向；读一段协作说明 |
| 看懂代码里的基础英语 | 函数和存放数据的名字；传进去和返回来；数据是什么类型；对象里有什么；条件、循环与方法；读懂一段代码说明 |
| 终端、文件与开发工具 | 文件放在哪里；终端中的一条命令；安装需要的软件包；构建与脚本；环境、配置与浏览器；照着 README 启动项目 |
| 错误、测试与调试 | 错误不都是一回事；测试通过了吗；读日志再定位；把问题写清楚；读懂缺失和权限提示；读一次失败报告 |

## 教学和题型

原作者 168 道题中，107 道考语境理解、40 道考词义、16 道考拼写、5 道考听音识别；新增候选题继续使用既有词语和例句，并显式标注知识目标、实际能力、难度和题面签名。实际出题从已介绍目标及本节确认的新目标中加权随机选择，不按上述数量或比例固定每轮。

编程英语不设置口语自评或朗读考核。低信心目标先使用有线索的识别，再过渡到语境或独立回忆，不要求首次见到 repository 这样的长词就盲写。作者综合题使用新 README、代码注释和失败报告，并包含否定、动作方向、输入与输出、警告与测试结果等容易误读的情况。本轮不重复同一题目 ID；有限预算结束后，尚不稳定的目标在后续动态课程中继续补学。

题型继续使用现有的 `choice`、`listen`、`order`、`fill`、`write`。指令排序把一条完整英文指令作为一个词块，答案按词块顺序以空格连接；不另外实现命令执行器。课程中的命令和路径仅是阅读材料，不会在电脑上执行。

## 词汇、声音与学习记录

课程用精确的 `word` 查找既有 `VocabularyItem.id`，缺词时直接报错，不能默默创建另一套 ID。每课 `wordIds` 列出本课教学目标；每题 `wordIds` 只列该题考查的目标，`ability` 区分 `meaning`、`listening`、`spelling`、`context`。`knowledgeIds` 使用 `word-{id}`，供共享课程进度记录定位具体知识。

教学卡的 `word-{id}` 和 `example-{id}` 直接读取词库的英文、中文及相同 ID 的 Aria / Guy 音频。新编写的阅读材料在题面和讲解中展示；不把其他录音冒充为这些句子的音频。听力题只使用已有单词录音。

确认教学只登记“正在学习”；实际题目、提示和错误继续保存，但不会因第一次教学或一次答对而进入长期复习。达到信心及间隔后换题独立完成的迁移条件，才获得 `readyAt`，由 `src/programmingProgress.ts` 桥接准入和真实词级证据。课程进度与日常英语独立保存，浏览、收藏和点读不代表答对。

历史手动标记的词是兼容例外：继续进入复习，并跳过作为新词的教学，不伪造分能力答题证据；出现困难后仍可回流补学。词汇库不再提供手动掌握开关。旧完成记录与学习状态保持，新增 `learning`、`adaptive` 等可选字段不重置历史会话；随机计划和已选题目保存后，刷新继续原题。

`src/programmingReview.ts` 让场景复习和词汇复习共用上述四项能力记录。场景选择题按明确的 `ability` 区分词义和阅读理解，指令排序属于语境；能力筛选、到期、难点和出题顺序均读取词级记录。长期复习中的新困难会降低对应学习目标的信心，影响下一节补学，原准入时间保留；纠正弱项后场景安排也会调整。共享课程内的旧课级记录保留作历史，不另作为编程词的掌握度。当前系统是本地规则，不调用新的 AI 或后台，也不是 Duolingo 私有算法的复刻。

## 验证

```powershell
node --test tools/test-programming-content.mjs tools/test-programming-practice.mjs tools/test-programming-progress.mjs tools/test-programming-review.mjs tools/test-adaptive-learning.mjs
npx tsc --noEmit
```

内容测试检查原材料的 4×6 结构、先教后考、综合范围不新增词、指定核心词覆盖、共享判题、完整指令块排序、教学文字与词库/声音清单一致，以及两套音频。候选题和算法测试另检查目标映射、动态轮次、提示防重、准入条件、刷新重放与有限结束。最终动态页面验收见 [课程系统说明](COURSE_SYSTEM.md) 与 `artifacts/adaptive-course/`；旧 48 课页面结果不能替代新规则验收。
