# 日常英语首批交付

日期：2026-09-15。

## 已实现的范围

在现有网站顶部切换“编程英语 / 日常英语”。本地地址仍为 `http://localhost:5186/`，部署仍为静态文件，没有新增账号、数据库、后台或运行时 AI 接口。

| 单元 | 内容 | 课程数 |
| --- | --- | --- |
| 打招呼与姓名 | 问候、姓名、姓名问答、确认身份、渐进书写和见面对话 | 6 |
| 来自哪里 | 来源、地点问答、否定、国籍及介绍整合 | 6 |
| 介绍身边的人 | 人称、身份、复数、状态、询问人物和连贯介绍 | 6 |
| 认识日常物品 | 物品、冠词、远近、复数、这些与那些；最后综合前四单元 | 6 |

合计 24 课、83 条唯一双语点读材料、120 道主练习和 48 道变式复查。其余主线单元仍是 [课程方案](DAILY_ENGLISH_CURRICULUM.md) 中的规划，没有用空入口表示已完成。

## 如何使用

1. 进入日常英语，选择单元和课程。先阅读简短说明、点读表达并跟读，再开始练习。
2. 练习包含选择、听音、词块排序、渐进填空、写句和表达自查。选择后先检查，再继续；错误会解释原因，适合的变体安排在后面复查，其他难点保留到后续复习。
3. 多空题可用 Tab / Shift+Tab、空格和方向键移动；单字母空自动前进。Enter 检查，反馈后 Enter 继续。输入法组合期间不提交。开放表达使用 Ctrl + Enter 完成自查。
4. “练习册”按已完成课程提供综合、理解、听音、书写和表达自查筛选。“复习”列出到期课程与未解决难点，也可提前巩固。
5. 离开课程、切换分区或刷新后，从“继续上次学习”恢复。当前题目、草稿、提示、反馈、纠错队列和结果均保存。

一次保留一轮进行中的练习。切换到另一课前页面会说明：已答记录保留，当前未提交输入不再续接；可以选择继续原课。切换界面风格、语音偏好或编程分区不结束当前日常课程。

12 道口语题现在提供“跟读示例 / 自己表达”。跟读时逐句点击麦克风，允许权限后开口读；识别文字与明确参考表达逐词对齐，标出未识别到的词、识别成其他词和多余词，可直接重读。全部句子匹配后完成跟读。第一课同时练 Hello 和 Goodbye；姓名等可变信息通过“自己表达”入口练习，不强制与示例姓名一致。

自己表达可用麦克风转成文字，也可手动填写、纠正识别结果，然后核对原题自查项。口语记录仍使用原来的 `self` 类别，不因此提升独立掌握或隔日记忆等级；没有自动发音、语法或作文评分。完整实现、使用限制和本次测试见 [口语识别接入](SPEAKING_PRACTICE.md)。

## 书写判题

填空结合题面组成完整句子后检查，写句和词块排序使用同一套书写匹配。例如 `I [空] Mia.` 接受 `am`、`’m`、`m`，不会因空格中没有完整的 `am` 而误判。

大小写、句末标点、多余空格及中英文撇号不影响结果；常见缩写和完整形式按句子匹配。没有限定句式的题目还收录明确等价的表达，例如“我叫 Ben”接受 `I’m Ben` 和 `My name is Ben`。美国名称的缩写及全称均可填写。

宽容处理不采用编辑距离猜词：人名、否定、单复数、缺词以及题目明确指定的句式仍参与判断。简短肯定回答保留完整形式，例如 `Yes, I am`；不能把 `Yes, I’m` 当作同义正确答案。口语识别、纠错安排和已有记录的存储格式不变。

回归脚本：`tools/test-written-answer.mjs`、`tools/test-daily-tolerance.mjs`；真实页面回归为 `tools/test-daily-tolerance-browser.mjs`，使用与下方浏览器验收相同的环境变量。

本次判题修复验收：TypeScript、115 项 Node 测试、生产构建和资源完整性通过。隔离 Chrome 完成 24 课全部主练习及原有 10 组日常场景；新增 16 个宽容判题场景在开发页面和构建成品均通过，涵盖 `m`、后续缩写、等价回答、多词填空键盘输入、确实答错和刷新保留。构建成品的两区真实点读及静态资源路径检查也通过。实际截图：[1440px](../artifacts/answer-tolerance/m-correct-1440.png)、[390px](../artifacts/answer-tolerance/m-correct-390.png)。已有历史答题记录不追溯改写，新提交使用本次规则。

## 记录与兼容

- `codewords-daily-v1`：版本、完成记录、理解/听力/书写/口语自查证据、错误及当前学习会话。
- 当前草稿可带可选 `speech: { mode, transcripts }`，按参考句 ID 保存最终识别文字，旧草稿没有此字段仍可读取。未完成的临时识别不写入进度；不保存录音。
- `codewords-section`：最后选择的学习分区。
- 沿用 `codewords-theme`、`codewords-voice` 和 `codewords-playback-speed` 作为共享偏好。
- 原有编程英语的掌握、收藏、测验、渐进复习等存储键、词汇 ID 与规则不迁移。相同单词在两个分区出现，不自动互相标记掌握。
- 课程完成、当次无额外帮助作答、跨日回忆及表达自查是不同证据；同日重复、看提示和立即纠正不会冒充跨日记忆。
- 损坏或未知版本记录保持原文，不覆盖为空记录。另一标签页更新记录时，旧页面停止保存，避免覆盖新进度；存储失败同样提示并保留本页输入。
- 正常可导出当前记录；出现保存问题时导出文件同时包含原存储文本与本页最新状态，以免遗漏未保存的草稿。当前没有自动导入或跨设备同步功能。

## 音频与构建

`public/audio/daily/aria/` 和 `public/audio/daily/guy/` 各有 83 个 MP3，共 166 个，约 2.25 MB。每个文件的文本、声线、合成参数、文件哈希和解码信息均在独立 `neural-manifest.json` 中记录。

生成只写日常音频目录：

```powershell
.venv/Scripts/python.exe tools/generate_daily_audio.py
python tools/verify_daily_audio.py
```

它使用已有 edge-tts 环境，没有新增前端依赖。示范点读只播放静态 MP3；麦克风识别另使用浏览器原生 SpeechRecognition。英文文本变化时按内容哈希更新；页面 URL 同时带文本版本，防止旧缓存与新文字不一致。

`npm run build` 校验构建副本，`npm run verify` 校验源目录；快速校验覆盖文件集合、文本、声线、合成参数和文件 SHA-256。完整音频解码额外运行 `tools/verify_daily_audio.py`，不把 FFmpeg 引入普通构建的依赖。

构建使用 Node.js 24，日常课程数据校验最低需要 Node.js 22.18。原有 3,560 词、Aria/Guy 各 7,121 个音频和旧 Piper 7,122 个音频基线继续检查。
