# 配色与动效改版

2026-09-27，依据已确认的可视化实现，未发布到线上或更新 Android 安装包。

## 界面

- 白色页面和导航，关键卡片、主按钮及分区选中态使用浅色渐变。蓝绿配色复用信源抓取与分析项目的按钮、卡片渐变，以及日程系统的插画渐变；另提供黑白、冰蓝、薄荷绿。
- 日常课程保留场景插画；编程课程突出当前真实目标对应的阅读例句。删除重复目标、安排说明和进度旁的泛泛介绍，保留真实轮次、目标词语、完成节数及导出。
- 课程、复习、词汇／表达库、收藏统一标题、控件和卡片。中文释义优先，词库与收藏沿用相同词条。日常复习展示已准入的表达、点读和相关表达练习，继续使用已有复习编排；编程复习保留词义、语境、拼写及听力练习。
- 分区切换比功能页切换更明显；课程内容、基础教程、音标选择、收藏、声音与同步设置增加局部反馈。连续切换取消旧动画，系统减少动态效果时关闭非必要运动。

## 状态兼容

保留 `codewords-theme`。旧值读取映射为 minimal → lagoon、sketch → pearl、print → sky、graffiti → mint；默认 lagoon。配色选择不重建练习。

本轮未修改课程抽题、适应性编排、学习数据格式、音频资源或同步协议。首页继续读取真实会话；未完成会话优先续接。浏览器验证使用隔离数据。
