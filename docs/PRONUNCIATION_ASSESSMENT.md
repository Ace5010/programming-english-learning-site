## 拟接入行为

1. 通关只看实际词句内容和发音清晰度，不使用音色相似度、与示范同步程度、语速、语调或综合韵律分数作门槛。正常发音变体须纳入验证，不能把一套词典音标当成唯一声学实现。
2. 有足够声学证据时，显示“哪个词、哪个音、建议怎么改”。例如目标 `think` 的 `/θ/` 被可靠识别为 `/s/`，才提示舌尖轻触上下齿之间并送气；不能仅凭转写 `sink` 反推用户一定发了 `/s/`。
3. 对弱音、连读、背景噪音、服务失败及模型分歧显示“这次未能确认”，保留重录和自查入口，不直接计为读错，也不伪造分数。正确词句只因重音或口音不同，不能被综合分数卡住。
4. 评测反馈放在对应句子下，保留正常／慢速点读和四种风格。重录、切题和退出取消旧请求，旧结果不得写进新题；正常录音后不自动重试产生额外调用。
5. 原始音频只用于当次评测，不写学习记录、不传同步服务；是否保存必要的评测反馈需保持现有存储兼容。口语结果不擅自变成词义、拼写或长期掌握的证据。
