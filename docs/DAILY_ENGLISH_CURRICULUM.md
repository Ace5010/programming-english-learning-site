# 日常英语课程方案 v1

日期：2026-09-15

状态：完整路线规划；前四个单元已实施为 24 节课程。实际功能和验收见 [首批交付说明](DAILY_ENGLISH.md)，其余路线仍为后续规划。

## 1. 这版解决什么问题

为现有网站增加一条从零基础走向独立使用英语的日常英语路线，让编程英语与日常英语可以同步学习。

原有编程英语作为独立分区保留：现有 3,560 条词汇及其分类、释义、音标、例句、音频、收藏、掌握记录和全部练习流程不动。即使其中有日常基础词，也不因新增分区而移走。日常英语另有课程进度，不自动继承或覆盖编程英语的掌握状态。

本方案综合已核对的代表性公开课程和分级资源，不是对互联网上所有课程的穷尽调查。下文的单元数量、先后顺序和练习安排是为这个网站重新编排的，不能称为多邻国官方课程目录。

## 3. 总体结构

| 部分 | 规划规模 | 目标 |
| --- | --- | --- |
| 发音与读写入门工具 | 4 个模块，随课穿插 | 会听辨、模仿、拼读和查音标，不先要求背完音标表 |
| 基础交流，目标 A1 | 16 个主题单元 | 介绍自己，理解和表达常见生活需求 |
| 日常生活，目标 A2 | 16 个主题单元 | 讲过去、说计划、处理常见服务与出行情境 |
| 独立表达，目标 B1 | 16 个主题单元 | 连贯叙述，解释理由，处理较完整的信息 |
| 深入交流，目标 B2 | 16 个主题单元 | 理解较长内容，表达并支撑观点，完成实用写作 |
| 进阶扩展，面向 C1/C2 需求 | 8 条扩展方向 | 长文本、细微语气、复杂讨论和真实项目；后续另编详细课程 |

**64 个主线单元是这版方案的组织规模，不是官方课程数量，也不是“学完必达 B2”的承诺。** 每个单元包含若干小课，复杂内容可以拆开；不强行把每个单元压成同样时长。阶段目标需要通过实际听说读写表现检验。

课程主要采用美式英语，延续 Aria / Guy 的语音偏好。随着水平提高加入其他常见口音和英美表达差异；有效的英语变体不应被机械判错。

## 4. 完整主线目录

表中的“完成任务”是练习与检查的方向，不表示完成几道题就已掌握。每单元都同时安排词汇、句型、听读输入和说写输出，语法解释服务于实际表达。

### 第一阶段：基础交流，目标 A1

参考 VOA 初学者情境、英国文化教育协会 A1/A2 语法及 A1 技能材料，重新安排先后顺序。先学完整的常用表达，再逐步解释其中的语法。

| 编号 | 交流主题 | 主要语言内容 | 完成任务 |
| --- | --- | --- | --- |
| A1-01 | 打招呼与姓名 | Hello / Hi / Goodbye；I am / I'm；姓名问答作为完整表达 | 听懂姓名，完成简短初次见面对话 |
| A1-02 | 来自哪里 | be 的疑问与否定；where；地点、国家与国籍 | 介绍来源并询问对方 |
| A1-03 | 介绍身边的人 | he / she / it / they 与 be；身份、职业、基础形容词 | 用几句简单话介绍一个人 |
| A1-04 | 认识日常物品 | a / an；名词单复数；this / that / these / those | 指认、询问并描述物品 |
| A1-05 | 我的东西与家人 | have / has；my / your / his / her 等物主限定词；名词所有格 | 说明归属，介绍简单家庭关系 |
| A1-06 | 数字、时间与日期 | 数字、价格、星期；what time；基础时间介词 | 听懂时间和价格，说明约定时间 |
| A1-07 | 我的一天 | 一般现在时肯定句、第三人称单数；日常动作 | 说出自己的日常安排 |
| A1-08 | 询问生活习惯 | do / does 的问句与否定；频率副词 | 互相询问作息和习惯 |
| A1-09 | 喜欢、想要与需要 | like / want / need；like + -ing；宾格代词 | 表达偏好与基本需求 |
| A1-10 | 家与周围环境 | there is / are；地点介词；房间、家具和社区地点 | 描述房间并说明东西在哪里 |
| A1-11 | 问路与交通 | 祈使句；方向、交通方式和路线表达 | 根据简短指路说明找到目的地 |
| A1-12 | 买东西 | how much / which；颜色、尺寸、基础形容词顺序 | 询问价格并选出合适商品 |
| A1-13 | 食物与点餐 | 可数与不可数名词入门；some / any；would like 作为点餐表达 | 点餐、确认数量并表达简单要求 |
| A1-14 | 能力与简单请求 | can / can't；Can I ...?；Could you ...? 作为礼貌请求 | 说出能做什么，并提出请求 |
| A1-15 | 现在正在发生什么 | 现在进行时；天气；与日常习惯作初步对照 | 描述眼前活动与天气 |
| A1-16 | 邀请与见面安排 | Let's ... / Would you like to ...?；接受、拒绝、确认 | 协商一个简单见面安排 |

阶段检查：换一组姓名、物品、地点和时间，完成听读理解、简短问答及几句个人介绍。不能只靠复述同一段背熟的对话。

### 第二阶段：日常生活，目标 A2

参考英国文化教育协会 A1/A2 知识范围，并综合 VOA 场景素材的组织方式。过去、未来和完成时逐步引入，不在一次练习里突然要求掌握全部变化。

| 编号 | 交流主题 | 主要语言内容 | 完成任务 |
| --- | --- | --- | --- |
| A2-01 | 以前是什么样 | was / were；过去的地点、状态与时间表达 | 对比以前和现在 |
| A2-02 | 昨天做了什么 | 一般过去时；常见规则与不规则动词；did 问句与否定 | 说明和询问已发生的事情 |
| A2-03 | 讲一个周末故事 | 先后顺序；and / but / because；过去时整合 | 按顺序讲清一件小事 |
| A2-04 | 比较商品与地方 | 比较级、最高级；常见不规则变化 | 比较两个选择并说出简单理由 |
| A2-05 | 数量与够不够 | much / many / a few / a little；too / enough | 讨论食物、数量、预算和需求 |
| A2-06 | 出行与计划 | be going to；用现在进行时表示已安排的活动 | 介绍近期计划并确认行程 |
| A2-07 | 决定与预测 | will；与已有计划的初步区别；可能发生的事 | 临时作决定或作简单预测 |
| A2-08 | 身体状况、建议与规则 | should / have to / must；不必与禁止的区别 | 描述常见身体感受，理解建议和规则 |
| A2-09 | 预约与服务 | 礼貌请求；日期、费用、需求的确认与复述 | 预约、入住或联系服务人员 |
| A2-10 | 当时正在做什么 | 过去进行时与一般过去时；when / while | 说明背景活动和打断它的事件 |
| A2-11 | 做过什么 | 现在完成时；ever / never；与明确过去时间对照 | 交流经历并补充简单细节 |
| A2-12 | 最近发生的变化 | just / already / yet；for / since 入门 | 说明已经完成、尚未完成和持续的情况 |
| A2-13 | 条件与结果 | 零条件句、第一条件句；未来时间从句 | 解释常见规律和现实条件下的结果 |
| A2-14 | 说清是哪一个 | 基础限定性关系从句；who / which / that | 用简单补充信息准确指认人和物 |
| A2-15 | 爱好、打算与目的 | 常见动词后的 -ing / to do；表示目的的不定式 | 说明喜欢做什么、打算做什么及原因 |
| A2-16 | 留言与日常邮件 | 请求、解释、安排；句间连接与基本段落 | 写清一封日常短邮件并读懂回复 |

阶段检查：完成一次预约或旅行安排，读懂通知与短邮件，叙述一次经历，留下包含时间、目的和请求的信息。

### 第三阶段：独立表达，目标 B1

参考英国文化教育协会 B1/B2 语法、B1 阅读与写作类型，并参考 VOA Level 2 的情境连续性。此阶段开始明显增加完整文本与自主组织语言。

| 编号 | 交流主题 | 主要语言内容 | 完成任务 |
| --- | --- | --- | --- |
| B1-01 | 生活发生了哪些变化 | used to；现在完成时与一般过去时巩固 | 讲清过去习惯和现在的变化 |
| B1-02 | 把故事讲完整 | 过去完成时；多种过去时与时间顺序 | 解释一件事发生前后的关系 |
| B1-03 | 一直在做与已经做完 | 现在完成进行时与完成时；持续、结果和状态动词 | 区分过程、持续时间和完成结果 |
| B1-04 | 未来的选择 | 多种未来表达；计划、安排、预测与现实条件 | 讨论计划及可能的调整 |
| B1-05 | 工作与学习经历 | 人物、职责和经历的描述；关系从句与常用搭配 | 连贯介绍自己的学习或工作情况 |
| B1-06 | 没听清时怎么办 | 间接疑问句；确认、复述、请求澄清 | 在信息不全时继续对话并问清需求 |
| B1-07 | 解释过程 | 现在与过去的被动语态；过程连接词 | 说明一个日常流程或产品如何制作 |
| B1-08 | 转达他人的话 | 间接陈述与间接问句；时间、人称和时态调整 | 准确转达信息和问题 |
| B1-09 | 表达可能性 | must / might / can't 等现在推测；确定程度 | 根据线索提出合理推测 |
| B1-10 | 假如可以选择 | 第二条件句；现实与假设的区别 | 讨论假设选择及其原因 |
| B1-11 | 解释自己的观点 | 理由、例子、简单让步；段落中的观点与支撑 | 给出有理由的意见并回应不同看法 |
| B1-12 | 解决问题与道歉 | 解释原因、道歉、提出办法；动词搭配与礼貌表达 | 处理误会、延误或服务问题 |
| B1-13 | 读懂信息与观点 | 主旨、事实与观点；指代、连接、基础改述 | 概括文章主要信息并识别作者意见 |
| B1-14 | 听懂访谈与故事 | 主旨、关键细节、事件顺序；基础笔记 | 听后复述要点并确认遗漏信息 |
| B1-15 | 写出连贯实用文本 | 邮件、评论、简短报告；段落组织与修改 | 写出目的清楚、信息完整的连贯文本 |
| B1-16 | 完成一个生活任务 | 阅读、听力、比较、沟通与说明的整合 | 制订一个出行或活动方案并解释选择 |

阶段检查：面对新的熟悉主题材料，提取信息、讲述经历、解释理由，完成连贯口头说明和短文；分别记录理解和表达中的薄弱点。

### 第四阶段：深入交流，目标 B2

参考英国文化教育协会 B1/B2 语法与 B2 技能目标。较复杂语法分多次小课练习，并持续用于真实任务，不集中刷完后搁置。

| 编号 | 交流主题 | 主要语言内容 | 完成任务 |
| --- | --- | --- | --- |
| B2-01 | 复杂经历与叙述视角 | 时态综合选择；背景、过程和结果的组织 | 清楚叙述较复杂事件并突出重点 |
| B2-02 | 推测过去发生的事 | must / might / can't have 等过去推测 | 根据不完整信息讨论可能原因 |
| B2-03 | 遗憾与不同结果 | 第三条件句、混合条件句；wish / if only，拆分教学 | 区分过去遗憾、现在愿望与假设结果 |
| B2-04 | 进度与截止时间 | 将来进行时、将来完成时；时间边界 | 讨论将来某时的进展和完成情况 |
| B2-05 | 正式说明过程与责任 | 被动语态扩展，包含情态与完成形式 | 准确描述流程、要求和已完成事项 |
| B2-06 | 准确转述立场 | 报告动词及其结构；观点归属与信息来源 | 区分谁提出、建议、承认或否认了什么 |
| B2-07 | 增加信息而不说乱 | 非限定性关系从句；指代与信息组织 | 在保持清晰的同时补充必要细节 |
| B2-08 | 建立有层次的论证 | 因果、对照、让步；although / despite / whereas 等 | 用不同理由与例子支撑观点 |
| B2-09 | 评估不同方案 | 修饰比较级；范围、程度和数量的准确表达 | 比较方案的收益、限制与适用条件 |
| B2-10 | 语气、立场与分寸 | 保留余地的表达；概率、礼貌与正式程度 | 根据对象调整表达，避免把猜测说成事实 |
| B2-11 | 阅读较复杂观点文章 | 推断立场、追踪论据、区分主张与支持 | 概括文章观点并解释判断依据 |
| B2-12 | 听懂较长自然语速内容 | 语篇标记、弱读与连读；结构化笔记 | 抓住较长讲话的主线和关键细节 |
| B2-13 | 正式邮件与提议 | 请求、投诉、建议；语域与段落安排 | 写出清晰、合适且有支撑的正式邮件 |
| B2-14 | 报告、评论与图表说明 | 筛选信息、比较、总结；详细写作与修订 | 根据给定资料形成有组织的文本 |
| B2-15 | 讨论与协商 | 接话、澄清、质疑、回应反对意见、形成结论 | 参与持续讨论并推动达成决定 |
| B2-16 | 独立完成综合项目 | 多来源听读、资料取舍、报告与口头说明 | 提交一个有依据的完整方案并回答追问 |

阶段检查：使用未练过的平行材料，完成较长听读任务、观点表达、正式写作和综合说明。只做选择题无法充分检验这一阶段。

## 5. 发音工具与进阶扩展

### 4 个发音与读写工具模块

| 编号 | 内容 | 使用时机 |
| --- | --- | --- |
| P-01 | 大小写、字母名称、拼出姓名与简单信息 | 第一阶段起，按实际需要补充 |
| P-02 | 常见辅音与元音的听辨和模仿 | 用正在学习的词训练，不一次灌入全部音标 |
| P-03 | 常见字母组合、音节与单词重音 | 随词汇积累逐步增加，并明确不规则情况 |
| P-04 | 句子重音、弱读、连读与意群停顿 | 从短句开始，随听力难度持续发展 |

这些是有目的的发音训练，不恢复用户已要求去掉的单词“拼写拆解”装饰模块。拼写练习继续渐进，不能把音标知识当作开始学习的门槛。

### 8 条进阶扩展方向

以下结合 CEFR 高阶能力描述及英国文化教育协会 C1 语法范围提出。它们是后续设计方向，尚不是完整 C1/C2 课程，更不意味着学完有限词表就包罗所有英语。

| 编号 | 方向 | 后续课程需要解决的任务 |
| --- | --- | --- |
| X-01 | 长文本与隐含意义 | 跟踪复杂论证、隐含立场和跨段联系 |
| X-02 | 多来源听力与综合 | 整合讲座、访谈和讨论，区分各方观点 |
| X-03 | 精确用词与语域 | 搭配、习语、近义表达、正式与非正式场合的区别 |
| X-04 | 高阶句法与信息重点 | 分词结构、省略、强调、倒装及其使用效果 |
| X-05 | 学术与专业写作 | 摘要、分析、提案、引述与反复修订 |
| X-06 | 持续论证与协商 | 即时回应、细致表达立场、处理复杂反对意见 |
| X-07 | 文化、文学与幽默 | 理解语境、隐喻、双关和表达习惯 |
| X-08 | 自选真实项目 | 围绕兴趣或实际工作完成长期输入、输出和修订 |

## 6. 单元为什么这样排序

安排先后顺序时主要检查四条依赖：

1. 先学简单的主语和 be，再学一般现在时，随后区分过去、正在进行、将来与完成。完整句子的成分解释随实际需要加入。
2. 先理解简单疑问和否定，再学更礼貌的请求、间接疑问和信息转述。
3. 先连接两个简单信息，再扩展关系从句、条件、让步、较复杂论证。
4. 先理解与复述短信息，再组织短段落，逐步处理长文本、多来源信息和自主表达。

同一生活主题会反复出现，但任务升级。例如第一次点餐只需选择食物；随后说明饮食要求与数量；再处理订单问题；最后才能对服务体验写出有理由的评论。

语法不只出现在主讲单元。冠词、代词、介词、主谓一致、可数性、量词、形容词与副词、动词搭配、短语动词、句子连接及常见标点会持续回收。每课编写时检查是否使用了尚未介绍的结构：必要表达可以先作为整句学习，不偷偷提高判题要求。

## 7. 每个单元实际怎么学

每单元包含以下六类学习活动；它们不是固定六道题，也不必恰好对应六节课。

| 环节 | 学习活动 | 难度控制 |
| --- | --- | --- |
| 认识情境 | 看或听简短对话，理解这次要完成什么 | 新词少量出现，初期提供清晰中文帮助 |
| 学会表达 | 学必要词汇、搭配和句型，做理解与配对 | 先确认意思，不立即要求整句默写 |
| 搭出句子 | 选词、排序、单空填空、替换练习 | 先少量选择，再逐渐撤去词库与提示 |
| 听懂并写出 | 听音选择、渐进听写、句子填空 | 从关键音或词过渡到完整表达，慢速可选 |
| 自己说和写 | 跟读、替换信息、独立回答或短文 | 从开口模仿开始，逐步减少模板 |
| 综合与复习 | 混合本单元和旧内容，纠错后换题再检查 | 不以立即重做原题正确代替长期掌握 |

小课先以约 5—8 分钟为设计起点，实际题量与时长通过试学调整；这是本网站的初步安排，不是多邻国官方时长，也不用于估算几个月必到某等级。

每课通常只引入一个主要新结构。新增词汇数量以能完成交流任务为准；“一个词”需区分词形、词义和搭配，不能只用累计数量代表学会了多少。

键盘操作作为练习设计的一部分：多空支持 Tab / Shift+Tab 顺序移动；需要逐格输入的练习提供合理的前进和回退；Enter 用于当前步骤的提交或继续；焦点跟随题目变化，输入法组合期间不误提交。具体自动跳转规则沿用并核对已有练习，不能改变其答案规则。

## 8. 第一单元示例：打招呼与姓名

下面是本方案自行编写的课程示例，不是从某个产品复制的题库。目标是能完成一次简短见面交流。

### 学习范围

核心表达：Hello / Hi / Goodbye；I'm ...；My name is ...；What's your name?；Are you ...?；Yes, I am. / No, I'm ...。

先把姓名问答作为完整表达认识，不要求用户第一课就解释其中全部语法。字母名称、大小写和拼姓名按需要接入 P-01。

### 小课安排

| 小课 | 内容 | 练习示例 |
| --- | --- | --- |
| 1 | 听懂问候和告别 | 听 Hello，选“你好”；换一段声音辨认 Goodbye |
| 2 | 说出自己的姓名 | 听 I'm Ben；将 I / am / Ben 排成句子；把 Ben 换成自己的姓名 |
| 3 | 询问姓名 | 学 What's your name?；听问句，选能回答姓名的回应 |
| 4 | 确认是否认对了人 | 听 Are you Mia?；理解肯定与否定回应，替换对话中的姓名 |
| 5 | 渐进回忆 | 先选出 am，再补全 I __ Ben，最后在撤去提示后输入完整目标句 |
| 6 | 完成见面对话 | 听一组已学表达组成的新对话，回答姓名；不看模板说出并写下自我介绍 |

第 5 小课中若写成 `I is Ben`，反馈说明“这里主语是 I，使用 am”，给出可点读的正确句，再用另一个姓名检查相同结构。这个帮助后的正确答案不直接算作独立掌握。隔后再练时，可以更换声线、姓名或问法，但不混入未教过的新句型。

严格补空题按明确目标判断；允许缩写的句子题应接受等价的 `I am ...` 与 `I'm ...`，合理处理大小写、句末标点和多余空格。开放自我介绍包含用户自己的姓名，不能用一条固定答案机械评分。

这一单元结束时应检查：能否辨认问候与告别、听出姓名、理解姓名问题、正确使用基础自我介绍，以及在没有词块提示时完成简短回答。

## 9. 练习册、复习与阶段检查

### 练习册的四个部分

1. **随课练习**：复用本课目标，增加不同姓名、物品和场景的平行题。
2. **专项练习**：针对时态、介词、词义、搭配、听辨或拼写等薄弱点练习。不会把所有专项都提前开放为必做内容。
3. **综合任务**：短对话、通知、邮件、文章与实际沟通任务，难度随阶段增加。
4. **纠错复查**：按错误涉及的知识点回看解释、完成帮助练习，再换题独立检查。

题目与课程目标使用同一份知识映射，避免“课上教一套，练习册考另一套”。内容编写时为每道题记录正确答案、可接受变体、解释、先修内容，以及音频对应文本。选择题检查是否出现多个合理答案。

### 复习记录的含义

日常英语需要区分“见过”“理解正确”“听辨正确”“独立拼写或造句正确”“依赖提示完成”。具体数据结构在实施阶段另行设计，不改动现有编程英语的存储格式和规则。

当天纠错解决当前问题；后续复习检查是否还能记起；阶段检查检验能否迁移到新例子。复习时间随正确性、提示使用和近期表现调整，不能把一个固定间隔表冒充已经验证有效的个人算法。

每 4 个主线单元设置一次整合检查，每阶段设置一次较完整的听说读写检查。使用已学词汇与结构组成新材料；分别呈现薄弱项，允许复习后再试。通过一道原题、刷完进度条或达到单一总分，都不足以证明已经达到某个 CEFR 等级。

不引入生命值、经验值、排行榜或奖励等级。反馈用于说明哪里会了、哪里需要再练。

### 口语和写作的实际边界

从第一阶段开始安排跟读、替换和独立表达。当前静态网站可以规划参考音频、文本提示、自我检查，及后续评估可行性的本地录音回听；这些新增能力尚未实现。

现有技术不能仅凭静态答案表可靠评价开放口语、发音质量或自由作文。初期开放任务使用明确的自查要求、示例与人工判断，不伪造自动评分。未来是否引入外部评估能力需要另行讨论，不在这版课程规划中新增 AI 接口、登录或后台。

## 10. 词汇、句子和材料怎么建设

- 以交流任务确定当前需要的词义，再参考 Oxford 的频率、实用性及等级信息检查优先级。并不宣称已把其全部词表覆盖进本方案。
- 词汇同时记录常用搭配和句子用法。一个多义词可在后续单元学习新的意义，不能“认识第一个意思就算全部掌握”。
- 保留词汇浏览和按主题检索的价值，但课程顺序不能只按“食物、动物、家具”分组，更不能按字母顺序推进。
- 初级例句用简单完整句，周围词汇尽量已经学过；逐步发展到连续对话和短文。中文解释保留，随水平提高让英文语境承担更多信息。
- 优先自行编写课程对话、解释、例句和题目；外部材料在适合时链接阅读。资源目录用于覆盖校对，不直接搬运整套专有题库、录音和插画。
- 新课程的每条录音必须与其文字一致，并检查单词、句子、声线、语速和缓存行为。没有制作的日常英语音频不标为现成可用。
- 原有编程英语词库、例句和音频不因新课程而重新生成。是否能复用某条已有音频，要按实际文本和音频内容逐条确认。

## 11. 与编程英语并行的使用方式

两个分区分别提供继续学习和复习入口。可以共享已选视觉风格、声线与语速偏好，但学习进度、错题和课程完成状态各自记录。相同单词在两个分区出现，不代表其不同语境已经同时掌握。

个人使用的初始节奏可以是编程英语约 10—15 分钟、日常英语约 15—20 分钟，再根据疲劳和复习积压调整。这只是试用建议，不是必须同时完成的每日任务；时间少时可以只复习或只学其中一个分区。

## 12. 后续落地顺序与验收

1. **先完成 A1-01—A1-04 的真实课程内容**：逐课词汇、句型、对话、题目、解释和答案变体；核对前后依赖，试学调整题量。
2. **接入一个可完整学习的流程**：学习、练习、纠错、隔后复习、学习记录。验证键盘操作、刷新保存、真实音频状态及两个分区互不干扰。
3. **扩充完整 A1，再逐步推进 A2、B1、B2**：每次扩充同时完成内容审核、音频校对和真实练习检查，不用空目录或重复模板表示课程已完成。
4. **达到足够的中高级学习需求后细编扩展课程**：按真实阅读、交流或写作任务进一步展开 C1/C2 方向。

课程验收要检查先修关系、句子自然度、解释准确性、难度、答案唯一性或有效变体、音频一致性和延后回忆。界面验收继续保留现有全部学习能力与存储兼容性；构建通过不能代替真实练习检查。

本方案形成时仅有课程规划。现已完成前四个单元的逐课内容、题目、录音和学习流程；其余 60 个主线单元及进阶扩展尚未制作，不将规划目录报告为已完成课程。
